# Hybrid Attendance Planner

A lightweight, open-source monthly planner for tracking hybrid office attendance.

## Features
- Clickable calendar month view
- Attendance states:
  - In Office
  - Work From Home
  - PTO
  - Work From Anywhere
- Attendance calculation:
  (# In Office Days / # Possible Days) × 5
- Data saved in browser localStorage
- No backend required

## Hosting on GitHub Pages
1. Create a new GitHub repo
2. Add these files
3. Repo Settings → Pages
4. Source: main branch / root
5. Open the provided URL ✅
